SanDisk, a Western Digital brand, is a leading manufacturer of flash memory products including memory cards, USB flash drives, solid-state drives, and embedded storage solutions. SanDisk provides developer SDKs for integrating iXpand storage devices into iOS applications, enabling third-party app developers to access and manage iXpand Flash Drive storage through the Lightning interface.

## APIs

### SanDisk iXpand SDK
The SanDisk iXpand SDK enables third-party iOS application developers to access and manage iXpand Flash Drive storage through the Lightning interface. It provides File System APIs with a familiar filesystem interface for managing storage operations, and System APIs that provide access to administration functionality.

- [Documentation](https://developer.westerndigital.com/develop/sandisk/ixpand-sdk-home-main.html)
- [Get the SDK](https://developer.westerndigital.com/develop/sandisk/get-the-sdk.html)

### SanDisk HQME SDK
The SanDisk HQME (Home Quality Media Experience) SDK is based on the IEEE P2200/D2 draft standard for content storage and retrieval on Android devices.

- [GitHub Repository](https://github.com/HQME-developer/SanDisk-HQME-SDK)
